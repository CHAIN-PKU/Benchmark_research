调研日期：2026-11-13。依据：08 号文档第一轮与第二轮；「未核」= 未在原文核实。我们的设定：单个具体模型（DeepSeek）、仓库级 SWE 题、严格事前（只有题面 + 仓库，无金标准补丁、不先跑任何模型）、标签来自该模型的历史 benchmark 结果、用途是路由省钱。

## 结论五行

1. 能否发表：能，但不能以「首个事前预测单模型成败」立论，该范式已有 ADeLe 等；可发表的是「把该范式首次推到仓库级智能体题、特征由单模型历史失败挖出、严格事前、小样本、并验证路由省钱」，前提是实验确实胜过基线。
2. 适合的顶会：软件工程方向（ICSE / FSE / ASE 的研究论文或 NIER 轨道，或 ESEM）最稳；机器学习方向可投 NeurIPS / ICLR 的 Datasets & Benchmarks 或评测相关研讨会；若效果强且有路由闭环，可冲 ACL / EMNLP（路由与评测方向）。
3. 能站住的新颖性：(a) 仓库级智能体题上的严格事前单模型预测（不用金标准补丁、不先跑）；(b) 特征从目标模型自己的历史失败中挖掘，而非预设量表；(c) 小样本（~100 题）下的表现与校准，并与 ADeLe 式量表、Pacchiardi 的参考集法、仓库先验三类基线对比；(d) 以路由省钱为终端指标。
4. 绝对不能声称：「首个」预测某模型能否解出某题的工作；「预测器优于所有已有方法」（除非真和 ADeLe 式、仓库先验基线跑过对比）；严格事前设定下沿用 Agent Psychometrics / Al-Haque 的 AUC 数字当自己的对照；以及「题面文本特征有效」（Al-Haque 的二手摘要提示仓库特征已解释大部分，未核实前不下结论）。
5. 还须核实后才能写进论文：ADeLe Nature 版的数字与是否含代码题、Reject Before You Run 与 PredictaBoard 的具体数字、CoDyn 原文、Al-Haque 与 Krsteski 的原文数字；提交前再检索一次 2026 年 9-11 月新出的 SWE 路由/assessor 论文。
