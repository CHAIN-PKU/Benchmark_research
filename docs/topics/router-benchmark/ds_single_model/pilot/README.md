## 过程中的问题与修复
1. 闸门脚本写死了已归档的题库路径 → caddy 两次在闸门前崩溃（agent 已正常跑完）。复制闸门脚本改路径，用 `finish` 从保存的输出补做闸门 + 评测，没重跑模型；这两条记录标了 `finished_post_hoc`，余额差缺失。
