# 第 5 章归因「查」：档案有没有写到真实失败点（2026-11-16）

对象：DS 真挂、且有阅卷归因的 38 道旧题（deep_attribution_46 ∩ 有档案）。
做法：Sonnet 对照「动手前档案」与「事后阅卷的失败点」，判 hit（写到具体点）/ partial（写到相关区域）/ miss。只用于事后分析，不进任何预测输入。38 次 Sonnet 调用。
脚本：chk_found.py（判定）、analyze_found.py（与判断者 p_fail 交叉）；结果 result.txt；逐题 out_found/。

## 结果
- **查得到**：hit 23（61%）、partial 14（37%）、miss 1（3%）。写到的位置以第 5 节「边界与隐含要求」最多（15），其次第 2、3 节（各 9）。
- **但掂量不出**：把这些挂题的 p_fail 放进 DS 做对题里排百分位（=该类 AUC）：

| 判断者 | hit 23 道 | partial 14 道 | 做对题中位 p_fail |
|---|---|---|---|
| 档案 + Sonnet | 0.68（进前 25% 的 57%） | 0.77（79%） | 0.30 |
| 档案 + Haiku | 0.62（43%） | 0.67（36%） | 0.35 |

## 读法
1. 「查」基本不是瓶颈：97% 的挂题，动手前档案已写到或靠近真实失败点。
2. 瓶颈在「掂量」：档案明确写到坑时，判断者仍有近一半没有把它排到高风险——因为做对的题的档案里也写着类似的坑，判断者分不出「哪个坑真会让这个模型掉进去」。
3. 与分节权重（history_use_ab）一致：第 5 节最常含真实失败点，也是单节最有用的风险分。
注意：判定由 Sonnet 给出，抽查 6 道 hit 引文均对得上；partial/hit 边界有主观性。
