# 第一性原理：模拟维护者写测试，量「隐藏测试的可预测性」（2026-11-16 夜）

出发点（crc 22:55「抓到最本质的问题」）：一道题挂 = 隐藏测试考了某个要求，且执行者没处理好。前者与执行者无关，后者才是执行者特有的；失败的根子是欠规范——题面和仓库没有唯一决定隐藏测试的期望。

## 分解测量（hit_label.py，Haiku；旧题 186 道、914 个坑，对照真实隐藏测试 diff）
- 坑被隐藏测试考到的比例 49%（444/914），每题平均 2.4 个。
- 被考到的坑，DS 栽的比例 11%；按类型：边界 9%、并列 8%、约定 7%，**题面误导 26%、定位 20%**。
- 被考到的坑数 → DS 挂率：1 个 10%，2 个 14%，3 个 39%，4+ 个 38%（「几个要求都满足才算过」）。上帝视角（知道被考到几个）对 DS 的 AUC 仅 0.65。
- 「被考到」的先验：类型 AUC 0.568，仓库 0.521（同仓库其它题的考点比例几乎不预测本题）。

## 模拟测试（test_sim.py，Haiku 采样 3 次）
| 量 | 结果 |
|---|---|
| 模拟测试票数 → 预测「坑被考到」（914 坑） | AUC 0.633；3 票 57% 被考到，0 票 17% |
| **模拟测试对真实隐藏测试的覆盖度 → DS 成败**（仅验证用，推理时不可得） | **AUC 0.731，相关 −0.36**：模拟能猜中的测试，DS 过；猜不中的，DS 挂 |
| 三份模拟之间的一致度 → DS 成败（推理时可得） | 0.483，无信号（Haiku 采样噪声，不是题的欠规范） |
| 「只能靠猜的期望」严重条数（assume.py，推理时可得） | 单独 AUC 0.615~0.637；0/1/2/3+ 条时挂率 9%/23%/34%/34% |
| 分解预测器 1−∏(1−票数/3·DS 各类失手率) | AUC 0.511（上帝视角版 0.654） |
| 以上任一加到校准后的 Sonnet / Haiku 上 | 无增益（区间跨 0） |

## 读法
1. 第一性原理得到验证：DS 的成败很大程度取决于「隐藏测试是否在题面和仓库的可预测范围内」（覆盖度 0.73，与 Sonnet 判断者 0.72 持平）。
2. 但推理时对这个量的估计很差：自我一致度无信号，「猜的条数」只有弱信号，组合无增益。瓶颈是「在做题前估出隐藏测试要什么」。
3. DS 特有的历史（失手率按类型）是稳定可解释的画像（T4/T5 显著更高），但它是第二因子；第一因子（考什么）估不准，整体预测就上不去。
4. 下一步（需先报账）：用更强的模拟器（Sonnet）并让它读仓库里同函数/同模块现有测试的写法，只在 60 道子集上先验证覆盖度能否提升；约 240 次 Sonnet。

## 补：出题人「历年真题」（test_sim_hist.py，Haiku，00:50；crc 00:19 的考试类比）
给模拟器看同仓库**其他**任务的真实隐藏测试（≤3 个，留一，不含本题），再写本题测试要点；覆盖度对照真实本题测试。185 道有同仓库其他任务。
| | 平均覆盖度 | 覆盖度 → DS 成败 AUC |
|---|---|---|
| 不看历年真题 | 0.512 | 0.739 |
| 看历年真题 | 0.514（配对差 +0.002，区间 [−0.021, +0.027]） | 0.727 |
读法：同仓库历年隐藏测试没有提升对本题测试的预测（Haiku 作模拟器）。题目有 18% 覆盖度上升、21% 下降。出题人习惯在这个粒度上不是可迁移的信息；rebench 上也基本用不了（100 道只有 2 道的仓库在旧题里出现过）。

## 补：Sonnet 当模拟器（test_sim_sonnet.py，60 道子集：30 挂 + 30 过，01:30）
覆盖度（模拟测试覆盖真实隐藏测试的比例）：Haiku 0.461 → Sonnet 0.579，配对差 +0.118，区间 [0.077, 0.159]；覆盖度 → DS 成败 AUC 0.770 / 0.776。DS 挂的题覆盖度 0.32 → 0.45，过的题 0.60 → 0.71。
读法：更强的模拟器确实更能猜中隐藏测试（信息缺口可以缩小）；但覆盖度需要真实测试，推理时不可得，还需要一个不看真实测试的代理指标。
文本分类器（TF-IDF，坑级 914 样本，按仓库 2 折）预测「坑被考到」0.49~0.53、「DS 栽」0.52~0.54：跨题稳定的是语义机制，不是文字表面。
