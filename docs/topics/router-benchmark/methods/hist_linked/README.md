# 联动历史：DS 挂/过 × 判断者判对/判错 → 历史经验文案（2026-11-16 晚）

起因：crc 19:08 / 19:16——看数据找每个模型判断差在哪；强模型判错的地方也要归因；把「DS 哪些做出来哪些挂」和「判断模型哪里判对哪里被误导」联动，整理成一份好的历史数据文案。

## 材料（每折各自整理，只用于另一折）
1. DS 做题侧：挂/过成对对比的区分清单（../contrast_pairs）+ 本折题按本折清单打分（scorein_haiku）得到每条「挂侧/过侧」历史挂率（out_con/anchors_fold*.json）。
2. 判断者侧：judge_err.py——档案 + Sonnet 判断，每折漏报 8、误报 8、判对 4+4，共 48 道 Sonnet 逐题归因（out_jerr/）。
   - 漏报：被「改动小、根因明确」骗，忽略了隐藏测试决定的二选一、题面误导（补丁方向反、平台字样、链接指错）、并列副本可能不改。
   - 误报：被「难查、难定位、隐藏测试未知」吓到；档案已钉死根因、改动局部、有现成先例的题 DS 都做对了——难查 ≠ 难做。
3. 弱判断者侧：DS / GLM 当判断者的误判归因（../bench_xmodel_predictors/out_disagree）。
4. hist_doc.py write（Sonnet，每折 1 次）把三类材料写成 ≤1500 字文案（out_hdoc/doc_fold*.md），judge 时给另一折的题。

## 结果（144 道共同题；排序 + 原始概率质量）
| 判断者 | 做法 | 与 14 家难度相关 | 14 家 AUC | DS AUC | ECE |
|---|---|---|---|---|---|
| Haiku | 无历史 | 0.476 | 0.692 | 0.634 | 0.168 |
| Haiku | + 区分清单（无数字） | 0.479 | 0.693 | 0.627 | 0.174 |
| Haiku | + 历史尺子（清单 + 挂率） | 0.492 | 0.696 | 0.601 | **0.092** |
| Haiku | + 历史文案 | **0.534** | **0.725** | 0.635 | 0.266 |
| Sonnet | 无历史 | **0.540** | **0.721** | **0.707** | 0.129 |
| Sonnet | + 区分清单 | 0.526 | 0.715 | 0.642 | 0.089 |
| Sonnet | + 历史文案 | 0.530 | 0.717 | 0.666 | 0.160 |
配对区间：Haiku 文案 − 无历史 相关 [−0.04, +0.16]；Sonnet 文案 − 无历史 DS AUC [−0.08, +0.00]。
历史文案组再用历史通过率平移校准：Haiku ECE 0.24→0.07，Sonnet 0.14→0.05，排序不变。

## 读法
1. 联动文案是目前对弱判断者最有效的历史用法：Haiku 排序 +0.06（区间跨 0），追到 Sonnet 无历史的水平（0.53 vs 0.54）。
2. 对强判断者没有增益，对 DS 特有的准度还略降：历史凝练出的多是通用难度知识，Sonnet 本来就会，加进来反而覆盖了它自己的判断。
3. 文案让判断者更悲观（Haiku 平均 0.50），需配合历史校准；校准后概率误差明显下降。
4. 限制：每折只有约 70 道题、约 20 次挂；历史材料来自单一执行者 DS。多模型、新题标签到齐后历史量翻倍，再验。

## 补：只学失败会不会更悲观（crc 19:33）
原文案「挂」的篇幅约是「过」的 2 倍；档案 7 节也几乎全是风险。两个对照（Haiku，各 157 次）：
| 做法 | 相关 | 14 家 AUC | DS AUC | 平均 p | ECE |
|---|---|---|---|---|---|
| 档案 + Haiku（无历史） | 0.476 | 0.692 | 0.634 | 0.40 | 0.168 |
| + 历史文案（偏失败） | 0.534 | 0.725 | 0.635 | 0.50 | 0.266 |
| + 平衡文案（成功/失败各半，先写怎么做对） | 0.471 | 0.691 | 0.618 | 0.43 | 0.201 |
| 不给历史，先列有利条件再列风险 | 0.470 | 0.690 | 0.646 | 0.37 | 0.135 |
读法：平衡后悲观确实减轻（0.50→0.43），先列有利条件也减轻（0.40→0.37），支持「只看失败/只看风险会偏悲观」；但都离真实 0.26 很远，可靠的修正仍是历史通过率校准。平衡文案的排序增益消失：偏失败文案的 +0.06 来自把判断者对挂侧信号「调敏感」，平衡后被稀释。
