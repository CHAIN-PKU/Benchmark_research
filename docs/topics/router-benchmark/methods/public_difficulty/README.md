读法：
1. DS 挂的题绝大多数是「大家都挂的难题」，不是 DS 独有的短板；题目难度是跨模型共享的。
2. 「历史没用」是用错了历史：仓库、话题层面的历史没信号，**同一道题上别家的结果**信号极强。
3. 局限：这个信号只在别人已经跑过这道题时存在；真正的新题（前瞻、SWE-rebench 新月份）一开始没有。它是「事前预测」的强参照/上限，也提示一条实用路线：先用便宜模型跑一次，再预测贵模型。
