# 固定技能表 + 统计拟合 + 5 折留出（2026-11-16 晚）

起因：crc 20:25 要求借鉴别人（含人类老师 / 认知诊断）的方法并反思 bug；20:35 要求纳入经验。思路：判断模型只负责「把题变成技能/陷阱标签」，概率由统计模型在训练折上拟合；对每个判断模型各拟合一套修正。

## 做法
1. taxonomy.py build：Sonnet 读全部 772 条档案里的「坑」，归纳固定的 13 项技能/陷阱表（out_tax/taxonomy.json）。**只用文本，不看成败**。
2. taxonomy.py tag：Haiku 对 186 道旧题各打 13 项 Q 向量（0~1）。
3. 5 折（按仓库分组，每折 35~41 题、8~10 次挂）：训练约 150 题（约 37 次挂），留出折只评一次。kfold_loop.py 做规则打分臂（起始规则只由训练折的成对对比得出，不迭代，因为前一轮证明迭代无增益）。
4. stack_eval.py：各臂的留出预测（常数、判断者原始 p、Platt 校准、Q 向量回归、Q + 判断者、规则打分）。

## 结果（186 道、DS 挂 46；5 折留出）
| 做法 | DS AUC [95%] | Brier（比常数） |
|---|---|---|
| 常数（历史通过率） | 0.50（无排序） | 0.1868 |
| Haiku 原始 p | 0.675 [0.58, 0.76] | 0.1985（+0.012） |
| Haiku p，经训练折 Platt 校准 | 0.662 | 0.1762（−0.011，区间 [−0.022, +0.001]） |
| Sonnet 原始 p | 0.724 [0.64, 0.80] | 0.1765（−0.010） |
| **Sonnet p，经训练折 Platt 校准** | 0.716 | **0.1659（−0.021，区间 [−0.037, −0.005]）** |
| 技能 Q 向量 → 回归（无判断者） | 0.585 [0.49, 0.68] | 0.1825（−0.004） |
| Haiku / Sonnet + 全部 13 项 Q（逐判断者修正） | 0.645 / 0.704 | 0.178 / 0.168 |
| + 训练折内选前 3 项 Q | 0.673 / 0.719 | 0.1741 / 0.1651 |
| 5 折规则打分（挂过对比规则，不迭代） | 0.686 [0.60, 0.77] | 0.1736（−0.013） |
（注：常数臂在 5 折下 AUC 不是 0.5，是折间常数不同造成的假象，排序意义上为 0.5。）

## 读法
1. 训练量有用：规则打分臂从两折（训练约 70 题）的 0.607 升到 5 折（训练约 150 题）的 0.686。
2. 概率层面第一次稳定赢过常数基线：Sonnet + 训练折 Platt 校准，Brier 比常数低 0.021，区间不含 0。这不是平移偏置，而是用判断者的排序加训练折成败拟合出的概率。
3. 逐判断者的 Q 向量修正没有显著增益（Haiku +0.00~+0.02，Sonnet ±0.01，区间都跨 0）：虽然能指出判断者被谁牵引，约 37 次挂的训练量学不出稳定的修正权重。
4. 技能表本身有信息（0.585，且 S6、S4 方向对），但弱于判断者；与判断者结合没增益，说明判断者已吸收了 Q 里能被文本看见的那部分。
5. 下一步：多执行者数据（DSH 在跑）→ 共享题目难度的 IRT；新题（rebench 100）作为真正前瞻留出。
