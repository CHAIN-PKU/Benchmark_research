# 候选方法实验记录

## 方法 1：叠加校准（2026-11-15 14:0x）——负结果
数据：186 道训练题（宽松口径挂 46 道）；随机分层 5 折 × 10 次，及按仓库分组 5 折。叠加器用内层交叉验证的单项分数训练，避免泄漏。脚本 stack_exp.py。

| 方法 | 随机 AUC | 换仓库 AUC | Brier |
|---|---|---|---|
| 大模型事前判断（Sonnet 读仓库，事前标签那组的 p_fail） | 0.677 | 0.677 | 0.176 |
| 相似题 kNN（题面 TF-IDF，k=10） | 0.50 | 0.51 | 0.205 |
| 同仓库历史挂率 | 0.45 | 无意义* | 0.21 |
| 简单特征（题面长度、提到的文件数、代码块数） | 0.45 | 0.47 | 0.195 |
| 事前知识点标签 → 回归 | 0.51 | 0.52 | 0.192 |
| **理想知识点标签（看答案）→ 回归，上限参照** | 0.67 | 0.68 | 0.170 |
| 叠加：大模型 + kNN + 事前知识点 + 简单特征 | 0.64 | 0.66 | 0.180 |
| 叠加：大模型 + kNN | 0.65 | 0.67 | 0.180 |
（全猜均值的 Brier = 0.186）
*按仓库分组切分时，测试仓库在训练折里不出现，仓库挂率按定义退化为常数，该格不应报数（2026-11-16 更正）。

### 补充诊断：历史信息为什么没用（2026-11-16，192 道，不花调用）
- 仓库间挂率无差异：31 个仓库 × 挂/不挂 卡方检验 p=0.69。
- 留一法仓库挂率 AUC 0.48；把标签随机打乱后同一算法的 AUC 均值 0.49（5%–95%：0.37–0.60）。即 0.45~0.48 与「零信号」无法区分，不是计算错误。
- 标签噪声：48 道宽松口径挂里 20 道是两次一过一挂。
- 结论：粗历史（仓库、题面话题）在本数据上不携带信号；待验证的是「同题他家成绩」（题目难度）与「按挂法匹配」的历史。

读法：
1. 所有「便宜」的历史信息基线都接近瞎猜：相似题、仓库挂率、简单特征、事前知识点都 ≈0.5。在 186 道的规模上，**历史标签本身几乎不携带可迁移信息**；能预测的只有「读这道题本身」。
2. 大模型事前判断（0.68）≈ 用标准答案打出的理想知识点（0.67~0.68）。即强模型读仓库，已经达到「知道这题真正需要什么」的水平。
3. 叠加不加分，略降：其余信号是噪声，回归把它们加进来反而稀释。
4. 推论：方法 2（检索相似历史题给预测员）预期收益很低（kNN 本身 0.50），降低优先级；更值得试的是方法 3（结构化取证：逼预测员列出并列位置/边界写法）和方法 5（多次采样分歧 → 选择性预测）。

## 机理实验：查证 vs 判断拆分（2026-11-15 17:0x）
问题（crc）：同样读仓库，为什么 Sonnet 比 DS/GLM 更会预测？
做法：取各预测员在 84 道上已产出的「证据」字段（≤3 条，文件:行号 / 题面原句），去掉它们自己的概率和风险分；只把「题面 + 证据」交给 Sonnet 做判断（不读仓库、不调工具、单轮）。脚本 judge_swap/judge_swap.py。

| 组合 | 题数（挂） | AUC |
|---|---|---|
| Sonnet 查 + Sonnet 判（原） | 81（15） | 0.68 |
| Sonnet 查 + Sonnet 只看证据重判 | 81（15） | 0.69 |
| DS 查 + DS 判（原） | 81（15） | 0.57 |
| **DS 查 + Sonnet 判** | 81（15） | **0.67** |
| GLM 查 + GLM 判（原） | 72（14） | 0.52 |
| **GLM 查 + Sonnet 判** | 72（14） | **0.66** |

DS 证据换 Sonnet 判断：+0.09（成对重抽样 −0.03~0.24，93% 为正）。
读法：
1. 弱模型查到的证据，交给强模型判断，准度几乎追平强模型自己查（0.66~0.67 vs 0.68）。**弱模型输在「把证据变成难度判断」，不在查证**。
2. 案例（redis-11631、immutable-js-2005、rubocop-13362、jekyll-8761）：DS 与 Sonnet 找到同一行代码、同一缺漏测试；Sonnet 据「定位准、改动小」判容易，DS 反判为难。
3. 方法含义：「便宜模型查证 + 强模型短判断」成本远低于强模型全程读仓库，准度接近——作为方法候选，需在前瞻测试集复核。
4. 局限：证据只有 ≤3 条摘要（判断者看到的信息比原预测员少）；样本小；反方向（Sonnet 查 + DS 判）待 DSH 用 DS 通道跑。

## 同一份证据、不同判断者：判断方式差在哪（2026-11-15 17:2x）
做法：统一用 Sonnet 在 84 道上查到的证据（≤3 条），只让各模型做判断，要求逐条列出「影响难度的因素 / 方向 / 分量 / 依据哪条证据」再给概率（脚本 judge_swap/judge_reason.py；不要求写思考过程——那样会被 Claude 的安全机制拦截）。

| 判断者 | AUC(p_fail) | AUC(「更难」减「更容易」加权分) | 平均失败概率 | 每题因素数 | 「更难」总分量 | 「更容易」总分量 |
|---|---|---|---|---|---|---|
| Sonnet | 0.70 | 0.74 | 0.28 | 4.8 | 4.7 | 4.7 |
| Opus | 0.69 | 0.70 | 0.30 | 5.0 | 4.8 | 4.7 |
| Haiku | 0.60 | 0.57 | 0.38 | 5.2 | **6.5** | **3.3** |
（DS、GLM 判断者由 DSH 补）

因素主题统计（关键词归类，84 道合计）：
| 主题 | Sonnet 判难/判易 | Opus | Haiku |
|---|---|---|---|
| 定位明确、单点修改 | 4 / 73 | 4 / 75 | **14 / 63** |
| 领域或逻辑复杂 | 0 / 0 | 4 / 0 | **12 / 1** |
| 隐藏测试可能会测更多 | 80 / 5 | 75 / 2 | **100 / 5** |
| 题面给了期望/复现 | 12 / 19 | 7 / 21 | 24 / 34 |

读法（初步）：
1. 同样的证据，Haiku 判得差，原因是**系统性地多列泛泛的风险**：「领域复杂」「隐藏测试可能测更多」这类几乎每题都成立的担忧，它当成分量大的「更难」因素；甚至把「定位明确」也有 14 次判为更难。结果是每题都显得难，分不开挂与不挂。
2. Sonnet、Opus 把「定位明确、改动小」稳定地当作容易信号，只在有**具体证据**（某条既有约定、某个并列实现）时才加「更难」——风险项是题目特有的，而不是通用担忧。
3. 用「更难减更容易」的加权分直接打分，Sonnet 能到 0.74，说明它列的因素本身就有区分力；Haiku 的因素加权只有 0.57。
4. 论文表述：弱判断者的问题不是「看不到」，而是「不会区分通用风险和本题特有风险」，导致判断失去区分度。

### 补：五个判断者齐了（DS、GLM 由 DSH 跑，2026-11-15 18:0x）
同一份 Sonnet 证据、宽松口径（至少挂一次）：
| 判断者 | AUC | 「更难」/「更容易」平均分量 | 平均失败概率 | 「定位明确」判难/判易 |
|---|---|---|---|---|
| Sonnet | 0.70 | 4.7 / 4.7 | 0.28 | 4 / 73 |
| Opus | 0.69 | 4.8 / 4.7 | 0.30 | 4 / 75 |
| Haiku | 0.60 | 6.5 / 3.3 | 0.38 | 14 / 63 |
| DS | 0.56 | **8.0 / 4.9** | 0.37 | 5 / 50 |
| GLM | 0.53 | 4.4 / **5.6** | 0.24 | 5 / 91 |
（DSH 按严格口径算 DS 0.51、GLM 0.52，结论相同。）

**更正上一节一个说法**：我原以为差别是「弱模型只列泛泛担心、强模型引用具体证据」。按「难点因素是否引用了具体文件」检验，这条不成立——Haiku 引用具体文件的比例反而最高（66%，Sonnet 48%），只计「有具体文件的难点」也区分不了。

**更站得住的描述（逐题并排看）**：五个判断者列出的难点**内容几乎一样**（例：lombok-3350、laravel-51195、fmt-3729，DS 与 Sonnet 列的风险点逐条对得上），差在**给每条风险定多大分量**：
- Sonnet/Opus：同一条风险在不同题上给的分量不同——改动集中、题面给了例子时，把「隐藏测试可能更严」降为中/小；所以分数能随题拉开。
- DS、Haiku：几乎把每条找到的风险都定为「大」，很少给「改动小」足够分量 → 普遍偏悲观，分不开。
- GLM：反过来，几乎每题都判「定位明确、容易」（91 次）→ 普遍偏乐观，同样分不开。
一句话：**弱判断者的毛病是「一刀切」的定分量方式（全悲观或全乐观），强判断者会按题目具体情况调整每条风险的分量。** 下一步用「同一判断者的风险分量在挂/过题之间有没有差异」量化这一点。

### 量化「分量会不会随题变」（机理指标初版）
指标：把判断者列的「更难」因素按分量（大3/中2/小1）求和，看这个分数本身能否区分挂/过（AUC）；同理看「更容易」分量（反向）。
| 判断者 | 难点分量 AUC | 利好分量 AUC（反向） | 难点定为「大」的比例：挂题 / 过题 |
|---|---|---|---|
| Sonnet | **0.73** | **0.72** | 0.14 / 0.07 |
| Opus | 0.67 | 0.71 | 0.15 / 0.10 |
| Haiku | 0.57 | 0.58 | 0.13 / 0.14 |
| DS | 0.54 | 0.53 | 0.28 / 0.21 |
| GLM | 0.53 | 0.55 | 0.11 / 0.12 |
读法：强判断者给风险/利好定的分量本身就随题目真实难度变化（两个方向的 AUC 都 ≥0.67）；弱判断者的分量与结果基本无关（≈0.53~0.58）。DS 把难点定为「大」的比例在所有题上都高（0.21~0.28），即整体偏悲观且不随题变。可作为论文中「预测能力 = 风险定分量的区分力」的机理指标。

## 价值验证初版：训练选题 & 评测估分（2026-11-15 18:5x，干净留出 104 道，Sonnet 通用提示）
1. **训练选题（找「五五开」的题）**：
| 预测失败概率 | 题数 | 两次都过 / 一过一挂 / 两次都挂 | 实际挂率 |
|---|---|---|---|
| <0.20 | 26 | 25 / 1 / 0 | 0.04 |
| 0.20~0.35 | 30 | 22 / 1 / 7 | 0.27 |
| 0.35~0.65 | 48 | 25 / **10** / 13 | 0.48 |
→ 预测中间段的题实际挂率 0.48（接近五五开），12 道「一过一挂」里 10 道落在这一段；预测 <0.2 的 26 道里 25 道两次都过——事前就能筛掉约 1/4 的「白跑题」。
2. **评测估分（不跑就估总通过率）**：预测均值 0.309，真实挂率 0.308；只抽 15 道真跑来估，平均误差 0.105；15 道真跑 + 预测校正，平均误差 0.093。
局限：留出集是公开题，预测员可能有记忆；需在前瞻 123 道和 SWE-rebench 100 道（2026-07 新题）上复核。
