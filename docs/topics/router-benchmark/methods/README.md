# 候选方法实验记录

## 方法 1：叠加校准（2026-11-15 14:0x）——负结果
数据：186 道训练题（宽松口径挂 46 道）；随机分层 5 折 × 10 次，及按仓库分组 5 折。叠加器用内层交叉验证的单项分数训练，避免泄漏。脚本 stack_exp.py。

| 方法 | 随机 AUC | 换仓库 AUC | Brier |
|---|---|---|---|
| 大模型事前判断（Sonnet 读仓库，事前标签那组的 p_fail） | 0.677 | 0.677 | 0.176 |
| 相似题 kNN（题面 TF-IDF，k=10） | 0.50 | 0.51 | 0.205 |
| 同仓库历史挂率 | 0.45 | 0.45 | 0.21 |
| 简单特征（题面长度、提到的文件数、代码块数） | 0.45 | 0.47 | 0.195 |
| 事前知识点标签 → 回归 | 0.51 | 0.52 | 0.192 |
| **理想知识点标签（看答案）→ 回归，上限参照** | 0.67 | 0.68 | 0.170 |
| 叠加：大模型 + kNN + 事前知识点 + 简单特征 | 0.64 | 0.66 | 0.180 |
| 叠加：大模型 + kNN | 0.65 | 0.67 | 0.180 |
（全猜均值的 Brier = 0.186）

读法：
1. 所有「便宜」的历史信息基线都接近瞎猜：相似题、仓库挂率、简单特征、事前知识点都 ≈0.5。在 186 道的规模上，**历史标签本身几乎不携带可迁移信息**；能预测的只有「读这道题本身」。
2. 大模型事前判断（0.68）≈ 用标准答案打出的理想知识点（0.67~0.68）。即强模型读仓库，已经达到「知道这题真正需要什么」的水平。
3. 叠加不加分，略降：其余信号是噪声，回归把它们加进来反而稀释。
4. 推论：方法 2（检索相似历史题给预测员）预期收益很低（kNN 本身 0.50），降低优先级；更值得试的是方法 3（结构化取证：逼预测员列出并列位置/边界写法）和方法 5（多次采样分歧 → 选择性预测）。
