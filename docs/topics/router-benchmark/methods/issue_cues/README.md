# 挂因 → 题面特征 → 预测新题（crc 11-16 01:02 要求，01:04 批准）

## 做法
1. 分题：SWE-bench Multilingual 300 道。总结集 = 不在前瞻集的 186 道；检验集 = 前瞻集里的 114 道（未参与任何总结）。
2. 阅卷（Sonnet，125 个有效案例）：总结集里 14 家公开智能体的失败，75 个「多数别家做对、这家挂」+ 50 个「多数都挂」。材料：题面、标准修复、隐藏测试、该家补丁、未过测试。输出挂因类型 + 题面线索 + 仓库线索。`grade_prompt.md`、`out_grade/`。
3. 归纳：12 条只看题面就能判断的特征，`cue_vocab_v1.md`，打标前冻结（`frozen_v1.sha256`）。
4. 盲打（Haiku，300 道，只给题面）：`out_tag/`。
5. 在总结集上拟合权重（14 家合并、各家截距；以及每家单独），冻结后在检验集上评估。`analyze_v1.py`，完整输出 `result_v1.txt`。

## 阅卷看到的挂因分布
- 「只有这家挂」（75）：改错地方 24、改坏原有行为 18、其他 15、没做完 6、并列漏改 5、隐藏要求 4。→ 多是执行粗心，题面线索少。
- 「大家都挂」（50）：改错地方 16、隐藏要求 10、并列漏改 6、题面说窄 6、没做完 6、改坏 5。→ 更多是题本身的坑。

## 结果
- 让人更容易挂的题面特征：C11 多种可接受做法（挂率 0.51 vs 0.32）、C08 输出形态没说死（0.48 vs 0.33）、C10 深层机制、C09 顺序/优先级、C12 新增能力。
- 反而更不容易挂的：C02 只举一个具体例子、C04 题面给了修法或位置、C06 特定特例、C07 边界措辞——题面越具体，越好做。
- 检验集 114 道，逐家 AUC：合并模型平均 0.57（0.48–0.63）；每家单独建模 0.56，没有更好。分数与 14 家公开难度的秩相关 0.16。
- 对照：Sonnet 读仓库的事前判断在旧题上逐家 0.61–0.76。

## 读法
1. 只看题面的特征有一点信号，但弱（0.57）；明显弱于读代码的判断。挂因线索多在代码里，与第 12 号文档的结论一致。
2. 起作用的是「题面没说清」（多种做法、输出形态不定），而「题面具体」保护做题者。这与「题目留白」类研究一致。
3. 每家单独建模不比合并好：从题面上看不出某一家的特有软肋，失败主要是共享难度。
4. 下一步可选：把这 12 条（含方向）作为判断 AI 的掂量规则来源，在 rebench 新题上和手写规则对比。
