## 读法
1. DS 的做题行为整体很一致，过与挂几乎没有区别：没有「少搜并列实现」「不跑测试」「少改文件」这类可抓的习惯性缺陷。
2. 仅有的两处差异（挂的运行跑更多次测试、更晚开始编辑）是「在难题上更折腾」，是难度的后果，不是原因；做题前不可见，不能用来预测。
3. 与前面技能表的发现一致：DS 的失败来自内容（期望行为没写明、与旧测试冲突），不是过程习惯。画像里「做题习惯」一栏应写成：稳定、不挑食、挂时更折腾，没有可作预测的特有行为缺陷。
