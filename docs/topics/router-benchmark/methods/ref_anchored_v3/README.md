# 参照式判断 v3（旧题开发，2026-11-16）

做法：186 道旧题，每道写案例卡（难点本质、动手前线索、DS 结果与原因）；判断时给 6 个案例（3 挂 3 过，只取另一折仓库），对比「不给 / 随机 / 难点相似（字符 n-gram TF-IDF）」。脚本 build.py、judge.py、analyze.py；完整数字见 result.txt。

| 判断者 | 不给案例 | 随机案例 | 相似案例 |
|---|---|---|---|
| Sonnet（186 道，46 挂） | 0.685 | 0.691 | 0.678 |
| Haiku（约 176 道） | 0.586 | 0.621 | 0.574 |

差值的配对重抽样区间都跨 0。

读法：
1. 给真实案例对强判断者没有增益。
2. 对弱判断者，随机案例有小幅提升（+0.03，不显著），像是「校准尺度」的作用；按难点挑的相似案例反而略差，字面相似的检索太粗。
3. 与此前所有「只判断、不读仓库」的实验一致：在同一份 3 条线索上，强判断者稳定在 0.68~0.72；而读仓库的完整预测在留出集上是 0.78~0.80。瓶颈更可能在「查到的线索够不够」，而不在判断时给什么提示。
