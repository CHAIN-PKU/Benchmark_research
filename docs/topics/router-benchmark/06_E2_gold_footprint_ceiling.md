# E2 天花板实验：标准答案改动规模能预测 DS 失败吗（2026-11-13，Claude）

**性质**：探索性，开发集，事后特征（标准答案在动手前看不到），只用来判断「改动规模」这条路值不值得投入。计入分析台账。

## 设置
- 题目：claw（真实 GitHub 修 bug，SWE-bench Multilingual + Verified-mini）中同时有标准答案和 DS 纯测试标签的 79 道，33 个仓库，DS 失败 14 道。
- 标签：`relabel_binary_20261112.csv`，model=DS，`fail_binary_pure`。
- 特征（取自标准答案补丁）：改动文件数、改动处数（hunk）、改动行数、FAIL_TO_PASS 测试数。
- 方法：单特征 AUC；四特征 log1p 标准化逻辑回归，按仓库分 5 折（种子 20261113），池化折外分数，按仓库整组 bootstrap 1000 次。

## 结果
| 特征 | AUC |
|---|---|
| 改动文件数 | 0.586 |
| 改动处数 | 0.587 |
| 改动行数 | 0.618 |
| 目标测试数 | 0.543 |
| 四特征逻辑回归（按仓库 5 折，池化） | **0.263** [0.116, 0.510] |

## 结论
- **未过闸门**（门槛：AUC ≥ 0.70 且下界 > 0.55）。最好的单特征 0.62，且这是在全部数据上直接看的，偏乐观。
- 组合后低于 0.5：14 个失败样本分散在 33 个仓库里，各折学到的方向不一致，说明这批数据撑不起任何多特征模型。
- 解读：在现有样本上，「完美知道改动规模」也预测不了 DS 失败。但只有 14 个失败，区间很宽，是「偏负面、样本不足」，不是定论。
- 对方案的影响：按 Fable 备忘录的约定，设计 2 的「改动规模」分支暂停；仓库侧探针要不要做，取决于能否扩到更多带失败样本的题。
