# godog 官方评测跑通记录（2026-11-13，Claude）

在服务器 `~/benchmark_router_paper/claude_eval/` 用独立 Python 环境（venv，没用线上平台那个）跑 Multi-SWE-bench 官方评测程序（commit 24f493f），整个过程不调用任何模型。

## 改了什么
原适配层（`ops/adapters/godog_instance.py`）有两个问题，导致官方评测无法判分：
1. `parse_log` 是空壳，永远返回 0 个测试 → 改成真正解析 `go test -json`，测试名格式与数据集一致（包路径::测试名）。
2. SWE-bench-Live 镜像里没有 `/home/test.patch` → 测试补丁以 base64 写进评测命令，只在评测容器里还原，答题 agent 看不到。
另外：存日志的目录名必须以 `pr-` 开头，官方报告生成器才收集得到；空补丁时跳过 `git apply`；补丁打不上就不跑测试（判未解决）。
