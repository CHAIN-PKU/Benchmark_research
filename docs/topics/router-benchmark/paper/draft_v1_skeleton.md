# 论文骨架 v1（2026-11-15 下午；在 v0 基础上按 crc 12:49 的立意重写主线）

暂定题目：**Can Models Foresee Coding-Agent Failure? A Prospective Benchmark for Pre-run Success Prediction on Repository-Level Tasks**
（中文：模型能预见编程智能体会挂吗？——仓库级任务事前成功预测的前瞻式基准）

## 0. 主张（三层，每层都有数据支撑或检验计划）
1. **失败是稳定的，不是掷骰子**：DS 每题两次运行，一致率 90%（随机期望 68%），κ=0.69；第一次挂的题第二次再挂 75%。
2. **存在稳定、可迁移的挂因**：训练集与干净留出集的失败类型比例几乎相同；从全部题出发、双模型独立标注的「多处并列修改」需求使 DS 挂率翻倍（42% vs 21%，CI 不含 0，κ=0.76）。
3. **事前预测这些挂因，是当前模型的短板，且模型间差异大**：强模型读仓库新题 AUC 0.78~0.80；DS/GLM 自评 0.47~0.57，JEV 0.35；即使强模型，事前认出「多处修改」的精确率仅约一半，事后存在的信号在事前被稀释。
→ 因此把「事前预测」本身做成基准：既能评估预测方法，也能刻画模型「预见能力」的缺口。

## 1. 基准定义
- **任务池**：仓库级编程任务（主批多语言 SWE-bench 风格、SWE-bench Pro、DeepSWE），抽题规则冻结 + sha256。
- **做题模型（被预测者）**：DS v4.1 flash 起步，扩到 5~6 个（便宜 → 强）。每题 ≥2 次，金标签 = 成功率；环境/评测故障按规则判 Invalid。
- **预测员（被测对象）**：任意模型/方法；输入 = 题面 + 基线代码快照（无历史），可选历史运行数据；输出 = P(fail)。
- **前瞻协议**：测试题的预测在做题模型运行前冻结（时间戳 + sha256 + 放行清单），从流程上排除泄漏。
- **赛道**：(a) 仅题面；(b) 可读仓库；(c) 可读仓库 + 历史运行数据；(d) 跨做题模型（预测 A 模型/B 模型各自成败）。
- **指标**：AUROC、AUPRC、Brier、校准误差；按仓库聚类的自助法区间；随机 / 换仓库 / 跨题库三种划分。

## 2. 基线
B0 先验（仓库/语言挂率）、B1 简单特征回归（题面长度、提及文件数、语言）、B2 强模型整体判断（通用提示）、B3 强模型 + 失败知识清单（v1/v2）、B4 任务需求标签 → 回归。

## 3. 分析
- 失败稳定性（重复运行一致性）与「差一点 vs 完全没做对」。
- 任务需求标签：事后（看答案）双模型标注一致性、挂率提升；事前召回/精确率；「事后有信号、事前被稀释」的量化。
- 失败过程（DS 轨迹）：照题面字面做 33%、自测太窄 31%、修症状 14%、不找并列实现 10%。
- 消融：读不读仓库、检索深度、失败知识有无、记忆隔离、预测员模型换档。
- 应用：用预测做路由的成本—成功率曲线。

## 4. 已有结果 / 待做
已有：稳定性、2×2、跨预测员、留出集（清单 v1≈通用）、细归因、需求标签事后/事前。
待做：前瞻测试集 123 道结果（今日放行完）、DeepSWE 32 道（清单 v2 vs 通用，预测已冻结）、B0/B1 正式基线、第 2~6 个做题模型、换仓库划分、路由曲线。

## 5. 风险
公开题记忆污染（隔离 + 前瞻 + 新题库缓解）；样本量；只有一个做题模型时结论外推受限（扩模型计划）；新颖性需与 ADeLe、PredictaBoard、IRT 类工作清楚区分。
