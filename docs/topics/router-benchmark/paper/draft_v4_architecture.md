# 论文架构 v4（2026-11-15 23:1x，按 crc 23:05 两点重写）

一句话：**用各模型的历史跑题数据 + 新题的题面和仓库，事前判断每个模型能不能做出这道题。**
两根支柱：A. 一个可复现的预测方法（和基线比）；B. 一个衡量「预测能力」的基准，并对模型之间的差距做逐层归因。

## A. 预测方法（要讲清楚「我们的方法是什么、比谁强」）
### A1 方法：两段式「查证 → 判断」+ 经验校准
1. 查证：模型在仓库里找证据（相关代码、并列实现、老测试、约定），可以用便宜模型做。
2. 判断：把证据交给判断力强的模型，按「本题特有的风险 vs 利好」定分量，给出概率。
3. 经验：给判断者看被预测模型的历史记录（做事习惯卡 + 成败对照例子 + 历史成败摘要），而不是机械的相似题挂率。
4. 多次判断取平均，分歧大的标「需要真跑」。
### A2 三个旋钮（消融）
| 旋钮 | 取值 | 现状 |
|---|---|---|
| 给多少信息 | 只题面 / 题面+自己读仓库 / +历史 | 只题面 0.41；读仓库 0.68~0.80；+历史：前瞻集已冻结，待揭晓 |
| 判断者多聪明 | Haiku / Sonnet / Opus / DS / GLM | 同证据：0.60 / 0.70 / 0.69 / 0.56 / 0.53 |
| 历史怎么用 | 不用 / 相似题挂率 / 历史记录 / 习惯卡+对照例子 | 相似题挂率≈0.50（无效）；后两种已冻结，待揭晓 |
### A3 基线（同一批前瞻题、同一标签）
历史先验、简单特征、kNN 相似题投票、IRT/知识追踪（理想/事前知识点）、大模型直接判断（通用提示）。
### A4 现状
- 已有：大模型读仓库远超所有便宜基线；手写失败清单、叠加校准不加分。
- 还没有：一个**明显超过「强模型 + 通用提示」**的方法。待揭晓的候选：方法 6（习惯卡+对照）、读历史、查证/判断拆分（DS 查 + Sonnet 判 0.67≈Sonnet 自己 0.68，但成本低得多）、多次平均。
- 关键检验：DS 跑完 123 道新题 + SWE-rebench 100 道后出主表。

## B. 基准 + 逐层归因（「为什么强模型会判、弱模型不会」）
用排除法，一层层排除假设：
| 假设：弱模型差是因为… | 检验 | 结论 |
|---|---|---|
| H1 查不到关键信息 | 把强模型的证据交给弱模型判；把弱模型的证据交给强模型判 | **排除**：DS 证据+Sonnet 判 0.67；Sonnet 证据+DS 判 0.51 |
| H2 只是整体偏高/偏低（刻度问题） | AUC 只看排序，不受整体偏移影响 | **排除**：弱模型排序本身就分不开 |
| H3 想不到有哪些风险 | 并排比各模型列出的风险点 | **排除**：风险点几乎一样 |
| H4 不会给风险定分量 | 用各模型自己给的分量打分看区分度 | **支持**：Sonnet 0.73 vs DS 0.54；DS/Haiku 一刀切悲观，GLM 一刀切乐观 |
| H5 不知道「哪类风险真的要命」（缺判断规则） | 给弱模型一份明确的定分量规则，看是否提升 | **待做** |
| H6 看不懂代码本身（理解力） | 用标准答案出「理解题」（这个并列函数要不要改？这个边界会不会被测？），比答对率 | **待做** |
| H7 随机波动 | 同题重复 3 次 | DS 标准差约 0.05，**基本排除** |
| H8 强模型是靠记得答案 | 在 2026-07 新题（SWE-rebench）上复核排名 | **待做**（预测已冻结） |
跨场景效度：判卷（题面+补丁，不跑测试）Opus 0.81 / Sonnet 0.74 / Haiku 0.60 / GLM 0.54 / DS 0.53，与事前预测强弱一致；DS 公开编程分高但判断最弱 →「会做题≠会判断」。
