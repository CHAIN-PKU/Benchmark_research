🧭 动手之前的判断力：论文骨架 v7

2026-11-16 傍晚 · 两条主线：把「事前预测」当 Benchmark 来测 ＋ 提出更好的预测方法 · Routing 等多模型数据齐了再放进第 7 章

💡 一句话：大模型能否在动手前判断「某个 Agent 能不能做成这道真实任务」？我们造了测量它的尺子（Benchmark），发现各模型差距大、差在掂量而不在看见，并提出「先查全成档案、再判断」的方法，比强模型直接判断更准。
标记说明：已有证据已锁定，等揭晓/在跑还没做

第 1 章 引言

  • 1.1 为什么需要「事前判断」：A2A 时代主 Agent 派活、不可逆操作、知道自己不行；人类社会靠简历和面试做同样的事。
  • 1.2 现状缺口：派活评测显示编排模型派对率只有 7.5%~29.5%（DecisionBench）；但没人直接测「动手前判断成败」这项能力本身。
  • 1.3 研究问题：RQ1 能否可靠测量、各模型差多少；RQ2 为什么有差异；RQ3 能否用更好的方法和信息提升；RQ4 能否转化为决策收益。
  • 1.4 贡献：① Benchmark 与先锁后揭晓的协议；② 能力差异与归因；③ 预测方法；④ 下游决策价值的初步证据。
希望读者记住：这是一项单独值得测、而现有模型普遍不擅长的能力。

第 2 章 相关工作

  • 2.1 模型路由与 Agent 派活：关注选谁、质量与成本；我们只研究其中可单独测量的「成功概率预测」环节。
  • 2.2 模型自知与校准：大模型普遍自信过头；训练可改善自我失败预测。
  • 2.3 题目难度与 Agent 成败预测：Agent Psychometrics（留出题 0.84，但用了标准答案和测试，且需见过该 Agent）；运行中途预测（EarlyEval）；评估器（PredictaBoard）。
  • 2.4 题面不清与提问：Ambig-SWE 等，解释为何「题面没说清」是失败主因之一。
定位：不做新路由器，测的是路由、派活、筛题背后共同依赖的那项能力。

第 3 章 怎么测（Benchmark 与协议）

  • 3.1 任务定义：输入题面 + 修复前仓库，输出目标 Agent 通过隐藏测试的概率；禁止看答案、测试、他人运行结果。
  • 3.2 题集：旧题 232（开发）；前瞻 123；SWE-rebench 2026-07 共 100 道（没人跑过的主测试集）；按时间和仓库切分。新题标签在跑
  • 3.3 目标 Agent：DS 为主，GLM、Sonnet、Haiku、Kimi 第二批；另用公开榜 14 家做免费多目标验证。多模型在排队
  • 3.4 协议：先锁预测（校验码、时间）再执行；逐题核对开跑时间；预注册干预；两种「挂」的口径。已实施
  • 3.5 指标：AUROC、Brier、LogLoss、ECE、分组置信区间、配对检验、每题成本与延迟。
结论目标：这把尺子可复现、防泄漏、能拉开模型差距。

第 4 章 谁判得准（主线 A：Benchmark 结果）

  • 4.1 便宜基线都接近瞎猜：仓库历史、相似题、只看题面特征 0.45~0.57；在 14 家公开 AI 上同样成立。已有
  • 4.2 模型差距：Sonnet、Opus 读仓库 0.68~0.80；Haiku、DS、GLM 接近瞎猜；DS 判断自己 0.47。旧题已有新题待复核
  • 4.3 会做 ≠ 会判：DS 做题约 75~80% 能做对，判断却接近瞎猜；判卷（只看补丁）排序与事前预测一致（Opus 0.81 > Sonnet 0.74 > …）。已有多模型「执行 × 预测」双排名表待数据
  • 4.4 上限参照：别家在同题上的成绩能到 0.91，说明失败主要源于题本身难；事前方法无法拿到，只作参照。已有
希望得到：①判断力能被测出且差距大；②执行能力和预测能力是两回事。

第 5 章 为什么有差异（归因）

  • 5.1 看见 vs 掂量：同一份线索交给五家，列出的风险几乎一样，掂量轻重的准度差很多；换线索实验中弱模型的线索交给强模型判，准度追上来。旧题已有新题复核（预注册）
  • 5.2 失败来自哪里：大部分是题本身难（各家共享），模型特有短板难以从题面看出；「题面没说清」比「题型」更能解释失败。已有
  • 5.3 历史信息为什么常常没用：按仓库或话题找的历史在 14 家上都约等于瞎猜；压成条目、一行案例都会丢信息。已有（负结果）
  • 5.4 是否只是没看懂代码：代码理解小测验，排除「看不懂」的解释。还没做
希望得到：差距在「把证据变成轻重判断」，而不在「找不找得到风险」。

第 6 章 怎么判得更准（主线 B：预测方法）

  • 6.1 方法：查证与判断分开。强模型查一次、按 7 节写成仓库档案（要改哪里、并列实现、现有测试与约定、边界、规模、难点）；判断模型看完整题面 + 档案（+ 完整历史案例）给概率。
  • 6.2 主结果（旧题 144 道）：档案比 3 条线索显著更准（+0.17~0.19）；档案 + Sonnet 优于强基线「Sonnet 直接读仓库判」（相关度 0.54 对 0.45，区间刚好跨 0）；档案 + Haiku 与强基线持平。已有新题预注册待做
  • 6.3 历史怎么给才有用：经验卡四组（预注册）；完整案例 vs 不给案例；按难点挑 vs 随机挑。在跑/等揭晓
  • 6.4 掂量能否被教：具体规则、通用清单、反写规则（预注册 77 道 × 4 个判断者）。等揭晓
  • 6.5 成本：查证每题约 35 秒、0.18 美元，判断可交给便宜模型；与直接判断、看答案上限对比。部分实测
  • 6.6 强基线：题目难度预测 + 模型整体能力；方法必须在它之上有增量。待算
  • 6.7 负结果：特征打分、取平均、粗历史、一行案例都不行——它们共同说明「信息完整度」是关键。已有
希望得到：在同样预算下，「查全成档案再判断」比强模型直接判断更准，且便宜模型可承担判断。打不赢就写成「便宜判断不掉队」。

第 7 章 有什么用（下游决策价值）

  • 7.1 Agent 派活 / Routing：离线反事实（公开榜 14 家有每题花费；rebench 多模型齐后）＋ 小规模端到端；对比随机、最便宜、最强、按历史、按难度、Foresight。等多模型跑完
  • 7.2 题目筛选：按预测挑 50 道排出的名次一致度 0.80 vs 随机 0.66（公开榜模拟）。初步
  • 7.3 训练数据筛选：可学缺口命中 17% vs 13%（弱证据）。初步
  • 7.4 省时间：预测约 20 秒 vs 真跑 10~30 分钟。实测
希望得到：更好的预测能转化成更好的派活和更省的评测；可路由空间小就如实说。

第 8 章 讨论与局限

  • 8.1 预测更多认出的是「题难」，模型特有短板仍难预测。
  • 8.2 模型估自己很弱，自知能力是开放问题。
  • 8.3 只覆盖代码任务；公开题有记忆污染风险，新题集用于主结论。
  • 8.4 未做训练闭环；RSI、Foresight-aware Agent Manager、动态多轮路由作为未来工作。

结论现状
① 事前预测可以超越「题目难度 + 模型整体能力」的简单基线对便宜基线已超越；对强基线待新题
② 执行能力排序与预测能力排序显著不同DS 已有初步证据，需多模型
③ 强预测器不是看到更多风险，而是更会掂量旧题证据最扎实
④ 预测差异能带来真实的派活收益等多模型数据
