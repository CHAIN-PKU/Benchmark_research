# 论文骨架 v0（2026-11-15，Claude 起草；数字均为当前中间结果，待留出集/盲测确认）

暂定题目：**Before You Run: Predicting Whether a Cheap Coding Agent Will Fail a Repository-Level Task**
（中文：动手之前——预测便宜编程智能体会不会在仓库级任务上挂掉）

## 0. 一句话贡献
路由器要在「派给便宜模型」和「派给强模型」之间选，关键是**事前**知道便宜模型会不会挂。我们发现：只看题面几乎猜不出（AUC≈0.41）；让一个会查证的模型按「错题本式清单」去仓库里找证据，能到 ≈0.7；这个能力强烈依赖预测模型本身（GLM/DS/JEV ≈ 0.35~0.57）。

## 1. 引言
- 背景：模型路由、成本—质量权衡；现有路由多用题面文本/难度标签，仓库级编码任务上信号弱。
- 问题定义：给定 issue + 基线代码快照（无历史），在 DS v4.1 flash 运行前预测 P(fail)。
- 贡献：(1) 两次运行 + 环境剔除的干净失败标签；(2) DS 失败的三类机制（隐藏要求/题面说窄/成对漏改）及反例；(3) 受控实验分离「信息 × 提示结构 × 预测模型 × 记忆」；(4) 留出集与跨题库（DeepSWE）检验。

## 2. 相关工作（见 08、09 两份文档）
ADeLe（Nature 2026，能力需求打分预测成败）、PredictaBoard、参考集预测器、路由器（RouteLLM 等）、SWE-bench 系列难度分析。区别：仓库级、事前、证据驱动、跨模型受控。

## 3. 数据与标签
- 题源：多语言 SWE-bench 风格集（主批）、SWE-bench Pro（v2 公开集抽样）、DeepSWE（113 道抽 40）；抽题规则写死 + sha256。
- 运行协议：500 轮 / 10800 秒、无网络、xhigh；每题 2 次。
- 标签：严格（两次都挂）/ 宽松（至少挂一次）两种口径都报；环境类失败剔除（env_exclusions）。
- 泄漏防护：泄漏门（precise_gate）、容器检查（无 /tests、无未来 git 历史、网络白名单）。

## 4. 失败归因（错题本）
- 方法：DS 补丁 vs 标准答案 vs 失败测试，逐题写原因；≥3 道支撑才成类；登记反例。
- 结果（28 道有效失败）：隐藏要求 ~40%、题面说窄、成对漏改、其他。
- 由此得到 5 步查证清单（v1-nomem，已冻结 sha256 12f109dd…）。

## 5. 预测实验设计（受控变量）
| 变量 | 取值 |
|---|---|
| 信息 | 仅题面 / 题面+自主搜仓库 / 题面+仓库+清单 /（待做）塞相关文件不许搜 |
| 提示结构 | 通用（不含失败知识）/ 笼统打分（含三类名称）/ 5 步清单 |
| 预测模型 | Opus、Sonnet、DS、GLM、Kimi（不全）、JEV |
| 记忆 | 允许 / 禁止 + 空 HOME 隔离 |
| 题集 | 提炼集 84（in-sample）/ 主批留出 104 / DeepSWE 32 / 盲测 8+8 |
指标：AUC + 自助法 95% CI；同题成对差值。

## 6. 结果（当前）
- E1 信息：仅题面 0.41 → 搜仓库 0.58~0.63 → +清单 0.68~0.71（提炼集）。
- E2 2×2（模型 × 提示）：提示主效应 +0.09（0.01~0.18）；模型主效应 +0.02（ns）。
- E3 记忆：0.74 → 0.69（禁用），剔除自报回忆题后 0.70。
- E4 跨模型（同一运行器）：Sonnet 0.68 / DS 0.575 / GLM 0.52 / JEV 0.35（严格口径 Sonnet 0.67 / DS 0.47 / GLM 0.44）。
- E5 留出集（进行中）：冻结清单 vs 不含失败知识的通用提示。
- E6 DeepSWE 迁移、盲测：待做。

## 7. 讨论
- 「错题本」是通病而非题目答案（crc 比喻）；真正风险是同批题既总结又评测 → 用留出集回答。
- DS 不能自评：路由不能让便宜模型自己判断。
- 预测器成本：Sonnet 每题 ~10~20 次检索；与直接跑 DS 的成本比较（待算）。

## 8. 局限
- 失败样本少（提炼集 15 / 严格 8），CI 宽；公开题有记忆污染风险；单一被预测模型（DS）；笼统提示含失败名称导致 E2 只能证明「结构」而非「知识」。
