🧭 动手之前的判断力

论文结构 v6 · 2026-11-16 上午 · 并入 crc 的定位与三个应用场景

💡 一句话定位（crc 11-16）
做一个 Benchmark：衡量不同大模型在「执行之前，预测某个编程 Agent 能不能做成一道题」上的能力；再研究能不能设计出更好的预测方法，以及为什么不同模型的预测能力有差异。
背后的大问题：能不能在模型真正动手之前，就摸清它在具体某道题上的能力边界？
评估→诊断→数据筛选→后训练→再评估
长期看，这个闭环是「探索智能上限」的一部分。本文只做第一环（可靠地测量这种判断力），并给三个应用的初步证据；完整闭环留给后续论文。

🎯 三个应用场景（crc 11-16）

三个场景背后是同一件事：动手前知道某个模型在某道题上的成功概率。本文各给一个小实验，不完整实现。

① 多 Agent 协作中的事前任务分配
Manager 拆完任务，要决定交给哪个 Worker。每次启动都有 token 和时间成本，能力又各不相同。先预测成功概率，再分配，可以少做无效执行、少重试。
小实验状态
模拟 Manager：只看预测概率，把题分给 DS / GLM 中更可能成功的一个。对比随机分配、总给最强、按历史平均分配。看同预算下的成功率和无效执行次数。等 77 道 DS + GLM 结果
要诚实写的：挂主要是题本身难（各家共享），所以分配的收益主要来自「难题交给强的、易题交给便宜的」。要证明「看人下菜」，需要预测里带上做题者身份，这一组正在补。
② 后训练数据筛选
很多候选题模型已经会了，或者难到产生不了训练信号。值得练的是能力边界附近的题。执行前就预测成功率，可以少做无效采样，更快找到能力缺口。
初步结果（公开榜 14 家 × 146 道，模拟）数值
按预测挑「最拿不准」的 30 道，其中「这家挂了、但别家有三分之一以上能过」（可学的缺口）的比例17%
随机挑 30 道的同一比例13%
方向对，幅度小，只是一个预测员、一次切分的结果。
③ Benchmark 题目筛选与构建
造 Benchmark 常出现没有区分度的题（都能做或都做不了）。提前预测各家成功率，可以挑出更接近能力边界、更能拉开差距的题，省评测预算。
初步结果（公开榜 14 家 × 146 道，模拟）排名一致度
按预测挑 50 道「中等难度」的题，排出的 14 家顺序与全部 146 道的一致度0.80
随机挑 50 道0.66
按预测挑 30 道 / 随机 30 道0.58 / 0.57
一致度是 Kendall τ（1 = 顺序完全一样）。50 道时有明显好处，30 道时没有；需要在新题和更多预测员上复核。

🤝 为什么这个能力必然有用（Agent 和 Agent 协作的时代）

  1. 协作离不开事前估计：任何协作系统都要分活，分活前先要判断「谁更可能做成」。没有它，只剩两条路：每个 Agent 把每件事都试一遍（成本随 Agent 数 × 任务数爆炸），或者固定一个最强的全包（又贵又浪费专长）。
  2. 人类社会早就这么做：简历、面试、试用期、项目分工，都是在没人真正干之前先估能力。估得越准，协作越便宜。Agent 更多、启动更贵、专长更细，所以更需要。
  3. 有些事根本不能「都做一遍」：改线上代码、发邮件、动数据库、花真钱，做了就收不回。只能事前判断：自己做、交给谁、还是先确认。Agent 越自主，这类任务越多。
  4. 「知道自己做不了」本身是能力：会说「我没把握，交给更合适的」或「先问清楚再动手」，比硬做、返工更有价值。今天的模型恰恰缺这个：DS 预测自己 0.47，文献也说大模型普遍自信过头。
  5. 所以要能「测」：不能假设模型有这种能力。强模型能估到 0.7–0.8，弱模型和「估自己」接近瞎猜。Benchmark 把「估得准不准」变成可测、可比、可改进的量。

还差的证据：Benchmark 分数高的模型，在真实决策（挑评测题、分配任务）上也做得更好。预算曲线和任务分配实验就是回答这个的；做出来，「有用」就从道理变成证据。

写法：Introduction 用一页讲必要性，随即落到「所以先要能测、能改进」；愿景放 Discussion。

🚀 长期意义：为什么这对 RSI 重要

起点：模型能在动手前判断「这件事我（或别的模型）做不做得出」。终点：更好的递归自我改进（RSI）——自己找短板、补短板、越变越强。

  1. RSI 是一个循环：找到做不到的地方 → 拿到针对性练习 → 训练 → 确认变强 → 再找下一处。
  2. 最贵的是「找」：今天只能把题全跑一遍才知道哪里挂；编程 Agent 一道题几十分钟、几块钱，候选任务成千上万。
  3. 事前预测把「找」变便宜：挑成功率 50% 上下的边界题来练；知道为什么挂（看不见 vs 掂不准），优化有方向；训练前后各预测一次，看边界是否外推。
  4. 预测别人就能帮别人：任务分给合适的模型，或为它生成针对性练习（老师带学生）。
  5. 所以这种判断力是 RSI 的「眼睛」。
这条逻辑的前提现状
能测、各模型有差别初步成立（强 0.7–0.8，弱≈0.5）
模型能认清自己不成立：DS 预测自己 0.47；文献也说普遍自信过头，但训练可改善
能说出「这个模型」的短板，而不只是「题难」偏弱：挂主要因题难；四组历史经验实验在检验
本文证明这只「眼睛」能被测量、能被改进；接上训练形成闭环是后续工作。

⚖️ 这篇论文说什么、不说什么

  • 说：这种事前判断力能被可靠测量；不同模型差异明显，差在「掂量」不在「看见」；能否通过规则和经验改善（预注册检验）；三个应用的初步证据。
  • 不说：已经完成「评估—诊断—数据筛选—后训练」闭环；能帮训练省钱（没做训练实验）；逐题预测很准。
  • 方法定位：新题上打败「直接让最强模型判断」就当主角之一；打不败就写成「便宜模型也能判得接近贵模型」的一章。

🌙 昨晚到今早做了什么

  1. 两个预注册实验，预测全部锁定：掂量规则 77 道 × 4 组 × 4 个判断 AI；经验卡 60 道 × 3 组 × 2 个判断 AI。锁定时这些题 DS 都还没跑。
  2. 找到公开榜单 14 家 AI 的逐题成绩：免费多出 14 个做题 AI。我们的预测在 14 家上都有效（0.61–0.76）；「别家挂几成」能到 0.91，说明挂主要是题难。
  3. 历史信息查清楚了：「用历史找相似题」在 14 家上都约等于瞎猜；有用的是把历史总结成经验——已写成「什么条件下才致命」的经验卡，在新题上预注册检验。
  4. 阅卷老师法：读 125 次挂题，总结 12 条题面特征，留出题上 0.57；题面没说清更容易挂，题面越具体越好做。
  5. 判卷补齐：220 道、五个模型，Opus 0.81 > Sonnet 0.74 > Haiku 0.60 > GLM 0.54 ≈ DS 0.51。
  6. 跑题（DSH）：新题约 45 道跑满两遍；77 道补上开跑前自检后在跑；GLM 通道修好；Sonnet 登录在服务器上配好。
  7. 筛题规则：先按质量淘汰、再分散仓库、最后随机抽 48 道，不看任何模型成败；规则已锁定。
