# 论文思路 v3 + 实验进度 + 待补清单（2026-11-15 21:3x）

暂定题目：**看到的一样，判断的不同：用「事前预测」测编程智能体的判断力**
（Seeing the Same, Judging Differently: Pre-run Success Prediction as a Probe of Judgment in Coding Agents）

## 一、论文思路（一条主线）
1. **问题**：一道没跑过的仓库级编程题，能否在动手前判断某个模型做不做得出来？实用价值：路由、评测省钱、强化学习选题（这些是动机，不是主卖点）。
2. **基准**：多题库真实任务 × 多做题模型 × 多预测员；先预测后运行（冻结+sha256+放行闸门）；每格多次；AUROC/Brier/校准/按仓库区间。
3. **发现一（谁能预测、靠什么）**：便宜的历史方法（相似题、仓库挂率、简单特征、事前知识点）≈瞎猜；读仓库的强模型能预测（新题 0.68~0.80）；手写失败知识、叠加校准都不额外加分。
4. **发现二（机理：看到的一样，判断不同）**：
   - 查证 vs 判断拆分：弱模型查到的证据交给强模型判 → 追平强模型；同证据换判断者 Sonnet 0.70 / Opus 0.69 / Haiku 0.60 / DS 0.56 / GLM 0.53。
   - 判断方式：风险点列得一样，差在定分量；强模型随题调整，DS/Haiku 一刀切悲观、GLM 一刀切乐观（风险分量 AUC：Sonnet 0.73 vs DS 0.54）。
   - 自我预测：DS 预测自己≈瞎猜且系统性悲观（与文献「普遍过度自信」相反）。
5. **发现三（这种判断力可迁移）**：判卷（题面+别人补丁，不跑测试）Opus 0.81 / Sonnet 0.74 / Haiku 0.60，与事前预测的强弱顺序一致；但「估工作量」普遍失败（高估约 3 倍）——判断力不是一种，要拆开看。
6. **干预（是否可改进）**：仓库推断的「需求落差清单」交给做题模型，看成功率是否上升（进行中）。
7. **价值验证**：预测中间段的题实际约五五开（训练选题）；预测均值≈真实挂率（评测估分）；路由成本—成功率曲线（待算）。
8. **局限**：公开题记忆污染；做题模型数量；样本量。
